## 1. What is the GitHub Student Developer Pack?

The **GitHub Student Developer Pack** is a set of free software tools, cloud hosting, domains, and premium licenses offered by GitHub and its partners to students. Its goal is to provide novice developers with the best professional tools on the market at no cost for the duration of their studies.

**Who can apply?**
Any student aged 13+ enrolled in a degree or diploma-granting course of study (high school, university, recognized bootcamp) who has an institutional email address or valid proof of student status.

---

## 2. Native GitHub Tools (GitHub Pro)

Upon activating your student pack, your GitHub account is automatically upgraded to **GitHub Pro**.

### 🤖 GitHub Copilot
- **Benefit:** Full free access.
- **Validity:** While you are a verified student.
- **Usage:** AI-powered autocomplete. Integrates directly into VS Code, JetBrains, and Visual Studio. Write comments about what you want to do and Copilot will generate the code.

### ☁️ GitHub Codespaces
- **Benefit:** 180 core hours per month for free.
- **Validity:** Monthly.
- **Usage:** Allows you to open any repository directly in the browser as a full VS Code environment with Linux. Excellent for coding from tablets or computers without setting up the local environment.

### ⚡ GitHub Actions
- **Benefit:** 3,000 monthly execution minutes in private repositories (up from 2,000).
- **Validity:** Monthly.
- **Usage:** Build CI/CD pipelines to automate tests and deployments directly on GitHub.

### 🏷️ "PRO" Badge and Advanced Features
- **Benefit:** PRO badge on your profile, 2GB in GitHub Packages, advanced branch protection rules, and GitHub Pages on private repositories.

## 3. Cloud & Hosting (Servers and Databases)

### 🌊 DigitalOcean
- **Benefit:** $200 USD in platform credit.
- **Validity:** 1 year.
- **Usage:** Ideal for setting up VPS servers (Droplets), managed databases, and deploying Docker containers or backend applications. Log in with your GitHub account to claim the credit.

### ☁️ Microsoft Azure
- **Benefit:** $100 USD in credits + access to over 55 free services.
- **Validity:** Annual (renewable while a student).
- **Usage:** Excellent for using Azure Functions, hosting SQL databases, and leveraging AI services from Azure Cognitive Services.

## 4. Free Domains and SSL

### 🌐 Namecheap
- **Benefit:** 1 year free of a domain name (e.g., .me) and free SSL certificate.
- **Validity:** 1 year per domain.
- **Usage:** Perfect for your personal portfolio (e.g., your-name.me). Go to the Namecheap for Students platform, link your GitHub account, and register it.

### 🌐 Name.com
- **Benefit:** 1 year free domain, Advanced Security privacy protection (WHOIS), and SSL.
- **Validity:** 1 year.
- **Usage:** Access via the GitHub portal, choose your ideal name, and use it for your professional projects.

## 5. Premium IDEs and Development Software

### 🧠 JetBrains Suite
- **Benefit:** Free educational license for **all** professional JetBrains IDEs (WebStorm, IntelliJ IDEA Ultimate, PyCharm Pro, DataGrip, GoLand, etc.).
- **Validity:** Renewable annually while a student.
- **Usage:** Create a JetBrains account with the same institutional email or link GitHub. You can download and activate any premium IDE for maximum productivity.

### 💻 Termius
- **Benefit:** Free access to Termius Pro.
- **Validity:** While a student.
- **Usage:** The best modern SSH manager. Allows you to save your server connections with autocomplete, visual SFTP, and secure sync across all your devices.

### 🐙 GitKraken
- **Benefit:** Free GitKraken Pro license.
- **Validity:** While a student.
- **Usage:** A visual Git client with a spectacular graphical interface to view the branch tree, resolve conflicts visually, and integrate directly with your Pull Requests.

## 6. Education, Courses, and Interviews

- **Frontend Masters:** 6 months of free access to premium advanced courses on JavaScript, React, CSS, Vue, etc.
- **Educative:** 6 months of access to interactive text-based courses with live code terminals in the browser.
- **Interview Cake:** 3 weeks access to the intensive course to learn how to pass technical programming interviews (algorithms and data structures).
- **Datacamp:** 3 months subscription to learn Data Science, Python, R, and Machine Learning at a professional level.

## 7. Step-by-step: How to claim the pack

1. Go to **[GitHub Education Pack](https://education.github.com/pack)**.
2. Sign in with your GitHub account.
3. Click on **"Get student benefits"**.
4. Add and verify your institutional university/school email address (the one ending in .edu or similar). If you don't have one, you will be asked to upload a photo of your student ID, transcript, or acceptance letter valid for this year.
5. Wait a few days for verification (sometimes it's instant, sometimes it can take up to 2 weeks).
6. Once approved, the "PRO" badge will appear on your profile and you can enter the **[GitHub Education Offers](https://education.github.com/pack/offers)** portal to claim each tool by clicking its respective "Get access by connecting your GitHub account on..." button.
