## 1. ¿Qué es el GitHub Student Developer Pack?
El **GitHub Student Developer Pack** es un conjunto de herramientas gratuitas de software, alojamiento en la nube, dominios y licencias premium que GitHub y sus socios ofrecen a los estudiantes. Su objetivo es brindar a los desarrolladores novatos las mejores herramientas profesionales del mercado sin costo alguno mientras duren sus estudios.

**¿Quiénes pueden aplicar?**
Cualquier estudiante mayor de 13 años matriculado en un curso de estudio que otorgue un título o diploma y que tenga un correo institucional o prueba válida de estudiante.

## 2. Herramientas de GitHub y Git
- **[GitHub Pro](https://github.com/pro):** Acceso gratuito a GitHub Pro mientras seas estudiante. (Potente colaboración, revisión de código y gestión).
- **[GitHub Copilot](https://github.com/features/copilot):** Suscripción a GitHub Copilot Student disponible para estudiantes verificados. Incluye autocompletado ilimitado, créditos de IA, chat y uso de agentes.
- **[GitHub Codespaces](https://github.com/features/codespaces):** Acceso nivel Pro gratuito para crear entornos de desarrollo seguros, configurables y dedicados directamente en el navegador.
- **[GitHub Pages](https://pages.github.com):** Un sitio por cuenta y organización, y sitios de proyectos ilimitados. Aloja webs estáticas directo desde tu repositorio.
- **[GitHub Desktop](https://desktop.github.com):** Herramienta Open Source de GitHub, gratuita para todos, que hace el flujo de trabajo de Git mucho más accesible.
- **[GitKraken](https://www.gitkraken.com):** El cliente Git de escritorio más popular. Integración profunda con GitHub. Plan Estudiante: Gratis por 6 meses y luego hasta 80% de descuento.
- **[GitLens](https://gitkraken.com/gitlens):** La extensión #1 de Git para VS Code. Plan GitKraken Student gratis por 6 meses.
- **[Tower](https://www.git-tower.com):** Cliente Git nativo para Mac y Windows. Licencia Pro gratuita mientras seas estudiante.
- **[WorkingCopy](https://workingcopy.app):** Cliente Git potente para iPhone y iPad. Todas las funciones Pro gratis mientras seas estudiante.
- **[Codecov](https://about.codecov.io):** Herramienta para implementar cobertura de código. Acceso gratuito en repositorios públicos y privados.

## 14. Cómo reclamar el pack paso a paso

1. Ve a **[GitHub Education Pack](https://education.github.com/pack)**.
2. Inicia sesión con tu cuenta de GitHub.
3. Haz clic en **"Get student benefits"**.
4. Añade y verifica tu correo electrónico institucional (el que termina en `.edu` o similar). Si no tienes, se te pedirá subir una foto de tu carnet estudiantil válido.
5. Espera unos días la verificación.
6. Una vez aprobado, podrás ingresar al portal de **[Ofertas de GitHub Education](https://education.github.com/pack/offers)** para reclamar cada herramienta.
