## 1. ¿Qué es el GitHub Student Developer Pack?

El **GitHub Student Developer Pack** es un conjunto de herramientas gratuitas de software, alojamiento en la nube, dominios y licencias premium que GitHub y sus socios ofrecen a los estudiantes. Su objetivo es brindar a los desarrolladores novatos las mejores herramientas profesionales del mercado sin costo alguno mientras duren sus estudios.

**¿Quiénes pueden aplicar?**
Cualquier estudiante mayor de 13 años matriculado en un curso de estudio que otorgue un título o diploma (instituto, universidad, bootcamp reconocido) y que tenga un correo institucional o prueba válida de estudiante.

## 2. Herramientas Nativas de GitHub (GitHub Pro)

Al activar tu pack de estudiante, tu cuenta de GitHub sube de categoría automáticamente a **GitHub Pro**.

### 🤖 GitHub Copilot
- **Beneficio:** Acceso gratuito completo.
- **Vigencia:** Mientras seas estudiante verificado.
- **Uso:** El autocompletado impulsado por inteligencia artificial. Se integra en VS Code, JetBrains y Visual Studio. Escribe comentarios sobre lo que quieres hacer y Copilot generará el código.

### ☁️ GitHub Codespaces
- **Beneficio:** 180 horas núcleo al mes gratis.
- **Vigencia:** Mensual.
- **Uso:** Te permite abrir cualquier repositorio directamente en el navegador como un entorno VS Code completo con Linux. Excelente para programar desde tablets o computadoras sin configurar el entorno local.

### ⚡ GitHub Actions
- **Beneficio:** 3.000 minutos de ejecución mensual en repositorios privados (antes 2.000).
- **Vigencia:** Mensual.
- **Uso:** Construye pipelines de CI/CD para automatizar tests y despliegues directamente en GitHub.

### 🏷️ Badge "PRO" y Features Avanzadas
- **Beneficio:** Insignia PRO en tu perfil, 2GB en GitHub Packages, reglas de protección de ramas avanzadas y GitHub Pages en repositorios privados.

## 3. Cloud & Hosting

### 🌊 DigitalOcean
- **Beneficio:** $200 USD en crédito para la plataforma.
- **Vigencia:** 1 año.
- **Uso:** Ideal para levantar servidores VPS (Droplets), bases de datos administradas y desplegar contenedores Docker o aplicaciones backend. Entra con tu cuenta de GitHub para reclamar el crédito.

### ☁️ Microsoft Azure
- **Beneficio:** $100 USD en créditos + acceso a más de 55 servicios gratuitos.
- **Vigencia:** Anual (renovable mientras seas estudiante).
- **Uso:** Excelente para usar Azure Functions, hospedar bases de datos SQL, y utilizar servicios de inteligencia artificial de Azure Cognitive Services.

## 4. Dominios Gratuitos y SSL

### 🌐 Namecheap
- **Beneficio:** 1 año gratis de un nombre de dominio (ej: .me) y certificado SSL gratis.
- **Vigencia:** 1 año por dominio.
- **Uso:** Perfecto para tu portafolio personal (ej: 	u-nombre.me). Ve a la plataforma de Namecheap for Students, vincula tu cuenta de GitHub y regístralo.

### 🌐 Name.com
- **Beneficio:** 1 año de dominio gratuito, protección de privacidad Advanced Security (WHOIS) y SSL.
- **Vigencia:** 1 año.
- **Uso:** Accede mediante el portal de GitHub, elige tu nombre ideal y úsalo para tus proyectos profesionales.

## 5. IDEs y Software Premium de Desarrollo

### 🧠 JetBrains Suite
- **Beneficio:** Licencia educativa gratuita para **todos** los IDEs profesionales de JetBrains (WebStorm, IntelliJ IDEA Ultimate, PyCharm Pro, DataGrip, GoLand, etc.).
- **Vigencia:** Renovable anualmente mientras seas estudiante.
- **Uso:** Crea una cuenta en JetBrains con el mismo correo institucional o vinculando GitHub. Podrás descargar y activar cualquier IDE premium para máxima productividad.

### 💻 Termius
- **Beneficio:** Acceso gratuito a Termius Pro.
- **Vigencia:** Mientras seas estudiante.
- **Uso:** El mejor gestor SSH moderno. Te permite guardar tus conexiones a servidores con autocompletado, SFTP visual y sincronización segura en todos tus dispositivos.

### 🐙 GitKraken
- **Beneficio:** Licencia de GitKraken Pro gratuita.
- **Vigencia:** Mientras seas estudiante.
- **Uso:** Un cliente visual para Git con una interfaz gráfica espectacular para ver el árbol de ramas, resolver conflictos (Merge Conflicts) e integrarse directo con tus Pull Requests.

## 6. Educación, Cursos y Entrevistas

- **Frontend Masters:** 6 meses de acceso gratis a cursos premium avanzados de JavaScript, React, CSS, Vue, etc.
- **Educative:** 6 meses de acceso a cursos interactivos sin videos, con terminales de código en vivo en el navegador.
- **Interview Cake:** Acceso de 3 semanas al curso intensivo para aprender a pasar entrevistas técnicas de programación (algoritmos y estructuras de datos).
- **Datacamp:** 3 meses de suscripción para aprender Data Science, Python, R, y Machine Learning a nivel profesional.

## 7. Cómo reclamar el pack paso a paso

1. Ve a **[GitHub Education Pack](https://education.github.com/pack)**.
2. Inicia sesión con tu cuenta de GitHub.
3. Haz clic en **"Get student benefits"**.
4. Añade y verifica tu correo electrónico institucional universitario/escolar (el que termina en .edu o similar). Si no tienes, se te pedirá subir una foto de tu carnet estudiantil, historial académico o carta de aceptación vigente con fecha de este año.
5. Espera unos días la verificación (a veces es instantánea, a veces puede demorar hasta 2 semanas).
6. Una vez aprobado, el badge "PRO" aparecerá en tu perfil y podrás ingresar al portal de **[Ofertas de GitHub Education](https://education.github.com/pack/offers)** para reclamar cada herramienta haciendo clic en su respectivo botón "Get access by connecting your GitHub account on...".
