## 1. ¿Qué es el GitHub Student Developer Pack?
El **GitHub Student Developer Pack** es un conjunto de herramientas gratuitas de software, alojamiento en la nube, dominios y licencias premium que GitHub y sus socios ofrecen a los estudiantes. Su objetivo es brindar a los desarrolladores novatos las mejores herramientas profesionales del mercado sin costo alguno mientras duren sus estudios.

**¿Quiénes pueden aplicar?**
Cualquier estudiante mayor de 13 años matriculado en un curso de estudio que otorgue un título o diploma y que tenga un correo institucional o prueba válida de estudiante.

## 2. Herramientas de GitHub y Git
- **GitHub Pro:** Acceso gratuito a GitHub Pro mientras seas estudiante. (Potente colaboración, revisión de código y gestión).
- **GitHub Copilot:** Suscripción a GitHub Copilot Student disponible para estudiantes verificados. Incluye autocompletado ilimitado, créditos de IA, chat y uso de agentes.
- **GitHub Codespaces:** Acceso nivel Pro gratuito para crear entornos de desarrollo seguros, configurables y dedicados directamente en el navegador.
- **GitHub Pages:** Un sitio por cuenta y organización, y sitios de proyectos ilimitados. Aloja webs estáticas directo desde tu repositorio.
- **GitHub Desktop:** Herramienta Open Source de GitHub, gratuita para todos, que hace el flujo de trabajo de Git mucho más accesible.
- **GitKraken:** El cliente Git de escritorio más popular. Integración profunda con GitHub. Plan Estudiante: Gratis por 6 meses y luego hasta 80% de descuento.
- **GitLens:** La extensión #1 de Git para VS Code. Plan GitKraken Student gratis por 6 meses.
- **Tower:** Cliente Git nativo para Mac y Windows. Licencia Pro gratuita mientras seas estudiante.
- **WorkingCopy:** Cliente Git potente para iPhone y iPad. Todas las funciones Pro gratis mientras seas estudiante.
- **Codecov:** Herramienta para implementar cobertura de código. Acceso gratuito en repositorios públicos y privados.

## 3. Cloud, Hosting e Infraestructura
- **Microsoft Azure:** Acceso gratuito a más de 25 servicios en la nube + `$100` en créditos Azure. Para estudiantes de 18+ años.
- **Microsoft Azure (13-17 años):** Acceso a servicios seleccionados como App Services, Functions, MySQL y DevOps sin tarjeta de crédito.
- **Heroku:** Plataforma fácil y flexible para desplegar apps. Crédito de `$13` USD al mes durante 24 meses.
- **Appwrite:** Plataforma de infraestructura de código abierto. Acceso gratuito al plan Education (equivalente a Appwrite Pro por `$40`/mes).
- **LocalStack:** Emulador de servicios AWS en tu laptop. Licencia gratuita para su entorno cloud listo para usar.
- **Pageclip:** Servidor para webs estáticas y formularios HTML. Plan básico gratis mientras seas estudiante.
- **Travis CI:** Plataforma de integración continua. Builds privados gratuitos mientras seas estudiante.
- **Zyte:** Plataforma cloud para web crawlers (Scrapy). 1 unidad de Scrapy Cloud gratis para siempre con retención de 120 días.

## 4. Dominios y Presencia Web
- **Namecheap:** 1 año de registro de dominio `.me` gratuito, más 1 certificado SSL gratis por un año.
- **Name.com:** 1 año gratis de dominio en extensiones seleccionadas (como `.live`, `.software`, `.dev`, etc.) más Advanced Security.
- **.TECH:** Un dominio estándar `.TECH` gratis por 1 año para mostrar que perteneces a la industria tecnológica.

- **JetBrains:** Suscripción gratuita a las IDEs profesionales de escritorio (IntelliJ IDEA, PyCharm, WebStorm, etc.), renovable anualmente.
- **Visual Studio Code:** Coding packs gratuitos de Microsoft para descargar todo lo necesario para empezar con Java, Python o .NET.

## 14. Cómo reclamar el pack paso a paso

1. Ve a **[GitHub Education Pack](https://education.github.com/pack)**.
2. Inicia sesión con tu cuenta de GitHub.
3. Haz clic en **"Get student benefits"**.
4. Añade y verifica tu correo electrónico institucional (el que termina en `.edu` o similar). Si no tienes, se te pedirá subir una foto de tu carnet estudiantil válido.
5. Espera unos días la verificación.
6. Una vez aprobado, podrás ingresar al portal de **[Ofertas de GitHub Education](https://education.github.com/pack/offers)** para reclamar cada herramienta.
