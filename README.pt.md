## 1. O que é o GitHub Student Developer Pack?

O **GitHub Student Developer Pack** é um conjunto de ferramentas de software gratuitas, hospedagem em nuvem, domínios e licenças premium que o GitHub e seus parceiros oferecem aos estudantes. O objetivo é fornecer aos desenvolvedores iniciantes as melhores ferramentas profissionais do mercado sem nenhum custo durante seus estudos.

**Quem pode participar?**
Qualquer estudante com mais de 13 anos matriculado em um curso de graduação ou diploma (ensino médio, universidade, bootcamp reconhecido) que tenha um e-mail institucional ou comprovante válido de matrícula.

## 2. Ferramentas Nativas do GitHub (GitHub Pro)

Ao ativar seu pacote de estudante, sua conta do GitHub é atualizada automaticamente para o **GitHub Pro**.

### 🤖 GitHub Copilot
- **Benefício:** Acesso gratuito e completo.
- **Validade:** Enquanto você for um estudante verificado.
- **Uso:** Autocompletar alimentado por inteligência artificial. Integra-se diretamente no VS Code, JetBrains e Visual Studio. Escreva comentários sobre o que deseja fazer e o Copilot gerará o código.

### ☁️ GitHub Codespaces
- **Benefício:** 180 horas-núcleo mensais gratuitas.
- **Validade:** Mensal.
- **Uso:** Permite abrir qualquer repositório diretamente no navegador como um ambiente VS Code completo com Linux. Excelente para programar a partir de tablets ou computadores sem configurar o ambiente local.

### ⚡ GitHub Actions
- **Benefício:** 3.000 minutos mensais de execução em repositórios privados (antes eram 2.000).
- **Validade:** Mensal.
- **Uso:** Crie pipelines de CI/CD para automatizar testes e implantações diretamente no GitHub.

### 🏷️ Badge "PRO" e Recursos Avançados
- **Benefício:** Selo PRO em seu perfil, 2GB no GitHub Packages, regras avançadas de proteção de branches e GitHub Pages em repositórios privados.

## 3. Cloud & Hosting (Servidores e Bancos de Dados)

### 🌊 DigitalOcean
- **Benefício:** $200 USD de crédito na plataforma.
- **Validade:** 1 ano.
- **Uso:** Ideal para criar servidores VPS (Droplets), bancos de dados gerenciados e implantar contêineres Docker ou aplicativos backend. Faça login com sua conta do GitHub para resgatar o crédito.

### ☁️ Microsoft Azure
- **Benefício:** $100 USD em créditos + acesso a mais de 55 serviços gratuitos.
- **Validade:** Anual (renovável enquanto estudante).
- **Uso:** Excelente para usar Azure Functions, hospedar bancos de dados SQL e usar serviços de inteligência artificial dos Azure Cognitive Services.

## 4. Domínios Gratuitos e SSL

### 🌐 Namecheap
- **Benefício:** 1 ano grátis de um nome de domínio (ex: .me) e certificado SSL grátis.
- **Validade:** 1 ano por domínio.
- **Uso:** Perfeito para o seu portfólio pessoal (ex: seu-nome.me). Acesse a plataforma do Namecheap for Students, vincule sua conta do GitHub e registre.

### 🌐 Name.com
- **Benefício:** 1 ano de domínio gratuito, proteção de privacidade Advanced Security (WHOIS) e SSL.
- **Validade:** 1 ano.
- **Uso:** Acesse pelo portal do GitHub, escolha seu nome ideal e use para seus projetos profissionais.

## 5. IDEs e Softwares Premium de Desenvolvimento

### 🧠 JetBrains Suite
- **Benefício:** Licença educacional gratuita para **todas** as IDEs profissionais da JetBrains (WebStorm, IntelliJ IDEA Ultimate, PyCharm Pro, DataGrip, GoLand, etc.).
- **Validade:** Renovável anualmente enquanto estudante.
- **Uso:** Crie uma conta na JetBrains com o mesmo e-mail institucional ou vincule o GitHub. Você poderá baixar e ativar qualquer IDE premium para máxima produtividade.

### 💻 Termius
- **Benefício:** Acesso gratuito ao Termius Pro.
- **Validade:** Enquanto estudante.
- **Uso:** O melhor gerenciador SSH moderno. Permite salvar suas conexões de servidor com autocompletar, SFTP visual e sincronização segura em todos os seus dispositivos.

### 🐙 GitKraken
- **Benefício:** Licença gratuita do GitKraken Pro.
- **Validade:** Enquanto estudante.
- **Uso:** Um cliente Git visual com uma interface gráfica espetacular para ver a árvore de branches, resolver conflitos (Merge Conflicts) visualmente e integrar-se diretamente aos seus Pull Requests.

## 6. Educação, Cursos e Entrevistas

- **Frontend Masters:** 6 meses de acesso gratuito a cursos avançados premium sobre JavaScript, React, CSS, Vue, etc.
- **Educative:** 6 meses de acesso a cursos interativos sem vídeos, com terminais de código ao vivo no navegador.
- **Interview Cake:** 3 semanas de acesso ao curso intensivo para aprender a passar em entrevistas técnicas de programação (algoritmos e estruturas de dados).
- **Datacamp:** 3 meses de assinatura para aprender Data Science, Python, R e Machine Learning em nível profissional.

## 7. Passo a passo: Como resgatar o pacote

1. Acesse o **[GitHub Education Pack](https://education.github.com/pack)**.
2. Faça login com a sua conta do GitHub.
3. Clique em **"Get student benefits"**.
4. Adicione e verifique seu endereço de e-mail institucional universitário/escolar (o que termina em .edu ou semelhante). Se não tiver, será solicitado que você faça o upload de uma foto de sua carteira de estudante, histórico escolar ou carta de aceitação válida deste ano.
5. Aguarde alguns dias pela verificação (às vezes é instantânea, às vezes pode levar até 2 semanas).
6. Assim que aprovado, o selo "PRO" aparecerá no seu perfil e você poderá acessar o portal de **[Ofertas do GitHub Education](https://education.github.com/pack/offers)** para resgatar cada ferramenta clicando em seu respectivo botão "Get access by connecting your GitHub account on...".
